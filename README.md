# React Task Manager

A responsive Task Manager built with React and JavaScript for organizing and managing daily tasks.

## Features

- Add new tasks
- Delete tasks
- Search tasks
- Filter tasks
- Set task priority: Low, Medium, High
- Add due dates
- Responsive design
- Clean and user-friendly interface
